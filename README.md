# Pavel Ryzhkevich

I maintain small self-hosted tools for real working sites and private service
workflows.

Current public project:

- [Zapiski Site Engine](https://github.com/ryzhkevichpavel-del/zapiski-site-engine) -
  a clean open-source extraction of a Python website engine for content,
  profiles, comments, media, admin editing, and compact self-hosted workflows.

Maintenance focus:

- safe self-hosting
- compact admin interfaces
- privacy-aware community features
- Python and SQLite services
- practical documentation for non-technical operators

The public repositories here are separated from private production
infrastructure: no live databases, deployment keys, server inventory, or user
uploads are published.
