# Тихий берег — Живой берег

Нативная трёхмерная песочница на Godot 4.7.1. Здесь можно непрерывно лепить и копать песок, проводить каналы, наливать воду, запускать большую волну, строить песочные башни и стены, бросать камни и оставлять плавучие коряги.

Проект использует аппаратный рендер, фиксированную физическую симуляцию и отдельное визуальное сглаживание между физическими шагами. Он не содержит WebView, Electron или браузерного runtime.

## Управление

- `1–0` — выбрать инструмент.
- `ЛКМ` — применить инструмент.
- `ПКМ` — вращать камеру.
- `Shift + ПКМ` или средняя кнопка — сдвигать камеру.
- Колесо — приблизить или отдалить.
- `WASD`, `Q/E` — перемещать точку внимания.
- `F` — вернуть хороший ракурс.
- `G` — большая волна.
- `H` — полдень / закат / ночь.
- `Ctrl+Z`, `Ctrl+Y` — отмена / повтор.
- `Ctrl+S` — сохранить.
- `F1` — справка, `F2` — настройки, `F3` — качество, `F4` — диагностика.
- `P` — фоторежим, `Space` — пауза.

## Сборка

Официальная CI-сборка экспортируется Godot 4.7.1 в Windows x64 и публикуется как GitHub Actions artifact. Локально проект открывается файлом `project.godot`.

```bash
godot --path .
godot --headless --path . -s res://tests/test_simulation.gd
godot --headless --path . -s res://tests/test_integration.gd
```

Полный перечень изменений находится в [`docs/IMPROVEMENTS.md`](docs/IMPROVEMENTS.md).
