# Критерии приёмки

CI не публикует Windows-артефакт, пока не выполнены все этапы:

1. Импорт проекта Godot без ошибок парсинга ресурсов и шейдеров.
2. Тест непрерывных инструментов песка.
3. Тест сохранения и восстановления состояния.
4. 180 шагов воды без отрицательной глубины и нечисловых значений.
5. Интеграционный тест башен, стен, камней и коряг.
6. Экранный запуск под Xvfb с реальным OpenGL-контекстом.
7. Создание контрольного PNG самой игрой.
8. Экспорт Windows x64 официальными шаблонами Godot 4.7.1.
